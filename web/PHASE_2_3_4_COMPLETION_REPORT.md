## 📝 使用场景

### 场景 1：批量分析实验数据

```
研究人员有 30 个 CZI 文件需要分析
→ 切换到批量模式
→ 拖拽上传所有文件
→ 设置参数
→ 一键分析
→ 导出 CSV 汇总表
```

### 场景 2：分析云端存储的文件

```
文件已存储在 S3（100MB+）
→ 切换到云存储 URL 模式
→ 粘贴预签名 URL
→ 输入文件名
→ 开始分析
→ 无需手动下载
```

### 场景 3：导出结果用于论文

```
完成分析后
→ 点击导出 JSON（保存原始数据）
→ 点击导出 CSV（用于 Excel 分析）
→ 点击导出图像（用于论文插图）
```

## 🐛 已知限制

### 云存储限制

- ⚠️ URL 必须可公开访问或使用有效的预签名 URL
- ⚠️ 下载超时限制：300 秒
- ⚠️ 仅支持单文件分析（批量需要本地上传）

### 批量分析限制

- ⚠️ 前端限制：最多 50 个文件
- ⚠️ 内存限制：取决于服务器配置
- ⚠️ 无队列系统：同步处理
