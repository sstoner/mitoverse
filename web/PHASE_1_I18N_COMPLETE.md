```typescript
// 简洁的使用方式
const { t, locale, setLocale } = useI18n();

// 基础翻译
```

## 🚀 使用指南

### 如何切换语言？

1. 点击导航栏右上角的语言切换器（地球图标）
2. 立即查看整个页面语言切换效果
3. 刷新页面，语言保持不变

### 开发者如何添加新翻译？

#### 1. 添加翻译键

在 `messages/zh.json` 和 `messages/en.json` 中添加：

```json
{
  "mySection": {
    "myKey": "我的翻译" // zh.json
  }
}
```

#### 2. 在组件中使用

```tsx
import { useI18n } from "@/lib/i18n";

function MyComponent() {
  const { t } = useI18n();

  return <div>{t("mySection.myKey")}</div>;
}
```

#### 3. 参数化翻译

```json
{
  "message": "Hello {name}, you have {count} messages"
}
```

```tsx
t("message", { name: "John", count: 5 });
// 输出: "Hello John, you have 5 messages"
```

## 💡 技术决策说明

### 为什么选择 React Context 而不是 URL 路由？

#### ✅ 优点：

1. **实施简单** - 无需重构整个应用结构
2. **快速部署** - 几小时即可完成核心功能
3. **用户友好** - 无 URL 变化，更流畅的体验
4. **灵活控制** - 完全掌控语言切换逻辑
5. **兼容性好** - 与现有代码无冲突

#### ⚠️ 缺点：

1. 不支持 URL 语言前缀 (`/zh/`, `/en/`)
2. SEO 需要额外配置 (可通过 `<html lang>` 标签优化)
3. 无法通过 URL 分享特定语言页面

#### 📈 未来优化方向：

如需 SEO 或 URL 语言支持，可后续迁移到完整的 next-intl 路由方案。当前方案已满足 MVP 和内部使用需求。
