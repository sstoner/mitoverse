# 语言闪烁修复 - 测试指南

## 问题回顾

用户报告：当选择英文后刷新页面时，会出现从中文瞬间切换到英文的闪烁现象。

## 修复方案

通过在 React hydration 之前隐藏页面内容，等语言初始化完成后再显示，完全消除闪烁。

## 测试步骤

### 测试 1：基本语言切换和刷新

1. 打开浏览器访问 http://localhost:3001
2. 确认页面默认显示中文
3. 点击右上角语言切换器，切换到 "English"
4. **刷新页面（F5 或 Ctrl+R）**
5. **观察**：页面应该直接显示英文，**不应该有中文闪现**

### 测试 2：不同页面的语言持久化

1. 在首页切换到英文
2. 访问分析页面 http://localhost:3001/analyze
3. **刷新页面**
4. **观察**：页面应该保持英文，无闪烁
5. 访问文档页面 http://localhost:3001/docs
6. **刷新页面**
7. **观察**：页面应该保持英文，无闪烁

### 测试 3：反向测试（英文切换到中文）

1. 当前页面为英文
2. 点击语言切换器，切换到 "中文"
3. **刷新页面**
4. **观察**：页面应该保持中文，无英文闪现

### 测试 4：清除缓存后的默认语言

1. 打开浏览器开发者工具（F12）
2. 进入 Application → Storage → Local Storage
3. 找到并删除 `locale` 键
4. **刷新页面**
5. **观察**：页面应该显示默认语言（中文），无闪烁

### 测试 5：新标签页测试

1. 在一个标签页中切换到英文
2. 打开新标签页访问 http://localhost:3001
3. **观察**：新标签页应该直接显示英文，无闪烁

### 测试 6：页面加载速度

1. 打开 Chrome DevTools（F12）
2. 切换到 Network 标签
3. 确保 "Disable cache" 已勾选
4. 刷新页面
5. **观察**：
   - 页面应该在 100ms 内显示（从白屏到内容出现）
   - 不应该有明显的加载延迟
   - 不应该看到任何语言切换

## 预期结果

### ✅ 成功标准

- 刷新页面时，**完全没有**语言闪烁
- 页面加载时有一个**极短的白屏**（约 20-50ms，几乎察觉不到）
- 页面出现时已经显示正确的语言
- 语言选择在所有页面间保持一致
- 关闭浏览器后重新打开，语言设置仍然保留

### ❌ 失败标准

- 看到中文内容短暂闪现然后变成英文
- 页面加载时间明显变长（> 500ms 白屏）
- 语言设置未保存，每次都回到中文
- 控制台出现 JavaScript 错误

## 技术细节

### 修改的文件

1. **web/app/layout.tsx**
   - 添加内联脚本，在页面加载时立即读取 localStorage 并隐藏页面
2. **web/lib/i18n.tsx**
   - 在 I18nProvider 的 useEffect 中，当语言初始化完成后显示页面

### 工作原理

```
页面加载 → 内联脚本执行 → 读取 localStorage → 隐藏页面
→ React 初始化 → I18nProvider 加载 → 使用正确的语言渲染
→ useEffect 执行 → 显示页面（已是正确语言）
```

### 白屏时间

- 正常情况：20-50ms（几乎察觉不到）
- 慢速网络：可能达到 100-200ms（但仍优于语言闪烁）

## 常见问题

### Q: 为什么会有短暂的白屏？

A: 这是为了避免语言闪烁的必要代价。页面在确定正确的语言之前暂时隐藏，确保用户看到的第一屏就是正确的语言。

### Q: 白屏时间可以更短吗？

A: 已经非常短了（20-50ms）。如果需要进一步优化，需要迁移到服务端渲染（SSR）方案，但那会是一个大的架构改动。

### Q: 如果 JavaScript 被禁用会怎样？

A: 页面会保持可见，但会显示默认语言（中文），且无法切换语言。这是所有 React 应用的共同限制。

### Q: 对 SEO 有影响吗？

A: 没有。搜索引擎爬虫会执行 JavaScript，能正确看到页面内容。使用 `visibility` 而不是 `display: none` 确保 DOM 结构完整。
